# 물류창고 AI 안전 모니터링 및 동적 경로 최적화

물류창고에서 로봇의 **위치·영상·센서 데이터를 실시간으로 수집**하고,
AI를 활용해 **작업자·장애물·낙상 등 위험 상황을 자동 감지**하며, 상황에 따라 **안전한 경로로 동선을 재계산**하는 로봇 관제 시스템입니다.

---

## 📌 프로젝트 배경

물류창고에서 이동하는 로봇은 단순히 정해진 경로를 반복하는 것만으로는 충분하지 않습니다.

실제 창고 환경에서는,

* 작업자가 로봇 이동 경로에 진입하거나
* 박스·팔레트 등이 통로를 막거나
* 작업자가 낙상하거나
* 기존에 계획한 이동 경로를 사용할 수 없게 되는

상황이 지속적으로 발생할 수 있습니다.

본 프로젝트는 이러한 문제를 해결하기 위해 로봇의 **위치·영상·센서 데이터를 실시간으로 수집**하고,
**YOLOv8 기반 작업자·물체 감지**, **MediaPipe Pose 기반 낙상 감지**, **그래프 기반 경로 탐색**을 결합하여 창고 내 위험 상황을 자동으로 판단하도록 설계했습니다.

로봇은 현재 위치와 목표 지점을 기준으로 **A* 기반 최적 경로를 계산해 이동**하며,
주행 중 작업자나 장애물 등이 감지되면 해당 구역의 위험도를 반영해 **경로를 동적으로 재계산**합니다.

또한 이상 상황 발생 시 관리자가 즉시 로봇에 개입할 수 있도록 **원격 조종 권한(Lease) 관리 기능**을 제공하며,
로봇 상태·이상감지 이벤트·경로 변경 이력을 데이터베이스에 저장해 사후 분석이 가능하도록 구성했습니다.

## ✨ 주요 기능

| 기능                 | 설명                                                                       |
| ------------------ | ------------------------------------------------------------------------ |
| **실시간 위치·상태 모니터링** | 로봇의 위치와 Heartbeat 정보를 수집하고 WebSocket을 통해 대시보드에 실시간으로 전달합니다.              |
| **최적 경로 탐색**       | 창고 통로를 Node·Edge 기반 그래프로 구성하고 A* 알고리즘을 이용해 현재 위치에서 목표 지점까지 최적 경로를 계산합니다. |
| **동적 경로 재계산**      | 작업자나 장애물 등 위험 상황이 현재 이동 경로에 발생하면 해당 구역의 Risk Cost를 반영하고 안전한 경로로 재탐색합니다.  |
| **작업자·물체 이상감지**    | YOLOv8을 이용해 작업자, 박스, 팔레트 등 객체를 감지하고 로봇 이동 경로와의 충돌 위험을 판단합니다.             |
| **작업자 낙상 감지**      | MediaPipe Pose를 이용해 자세 Landmark를 추출하고 시간 흐름을 반영한 Rule 기반으로 낙상 여부를 판단합니다. |
| **AI 판단 근거 생성**    | LangGraph Agent가 감지 이벤트, 로봇 상태, 현재 경로 등을 기반으로 위험도와 판단 근거, 권고 행동을 생성합니다.  |
| **디바이스 인증**        | 장치 토큰 기반 인증을 적용해 로봇과 연결된 Edge Agent의 접근을 검증합니다.                          |
| **원격 조종 Lease 관리** | 동시에 여러 사용자가 로봇을 조종하지 못하도록 한 명에게만 제어 권한을 부여하고, 일정 시간이 지나면 자동으로 권한을 반납합니다. |
| **데이터 영속화**        | PostgreSQL과 Alembic을 활용해 로봇 상태, 이상감지 이벤트, 경로 및 재계산 이력을 저장·관리합니다.         |
