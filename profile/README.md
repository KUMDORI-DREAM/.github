# 순찰 로봇 이상감지 모니터링

로봇의 **위치·영상·센서 데이터를 실시간으로 수집**하고,  
AI를 활용해 **이상 상황을 자동 감지 및 판단**하며, 필요 시 관리자가 **원격으로 로봇을 제어**할 수 있도록 지원하는 모니터링 시스템입니다.

---

## 📌 프로젝트 배경

기존 원격 모니터링 시스템은 영상이나 센서 데이터를 화면에 표시하는 수준에 머무르는 경우가 많습니다.

이 경우 실제 이상 상황이 발생했을 때,

- 왜 이상 상황으로 판단했는지
- 실제로 경보를 발생시켜야 하는 상황인지
- 관리자가 어떤 조치를 취해야 하는지

를 결국 사람이 직접 영상을 확인하고 판단해야 합니다.

본 프로젝트는 이러한 문제를 해결하기 위해 로봇의 **위치·영상·센서 데이터를 실시간으로 수집**하고,  
**YOLOv8 기반 이상감지**와 **LangGraph 기반 AI 판단 에이전트**를 결합하여 이상 상황을 자동 분석하도록 설계했습니다.

또한 이상 상황 발생 시 관리자가 즉시 로봇에 개입할 수 있도록 **원격 조종 권한(Lease) 관리 기능**을 제공하며,  
상태 이력과 이상감지 결과를 데이터베이스에 저장해 사후 분석이 가능하도록 구성했습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| **실시간 위치·상태 모니터링** | 로봇의 위치와 Heartbeat 정보를 수집하고 WebSocket을 통해 대시보드에 실시간으로 전달합니다. |
| **이상감지 및 판단 근거 생성** | YOLOv8이 카메라 프레임에서 낙상 등의 이상 상황을 감지하면 LangGraph Agent가 경보 여부와 판단 근거를 생성합니다. |
| **순찰 지도 관리** | 순찰 구역 지도(PNG)를 업로드·조회하며, 서버가 재시작되어도 최신 지도를 복원할 수 있도록 관리합니다. |
| **디바이스 인증** | 장치 토큰 기반 인증을 적용해 로봇과 연결된 Edge Agent의 접근을 검증합니다. |
| **원격 조종 Lease 관리** | 동시에 여러 사용자가 로봇을 조종하지 못하도록 한 명에게만 제어 권한을 부여하고, 일정 시간이 지나면 자동으로 권한을 반납합니다. |
| **데이터 영속화** | PostgreSQL과 Alembic을 활용해 로봇 상태 이력과 이상감지 로그를 저장·관리합니다. |
